# TLI Builder Data Notice

The TLI Builder source code is MIT-licensed (see LICENSE). This notice
covers the game data, which is handled separately.

## Where the data comes from

TLI Builder's dataset is aggregated from community sources and from the
game itself, then restructured, extended, verified, and kept current for
this project each season. Most of it comes from TLIDB, the community
Torchlight: Infinite database, used with permission and with full credit
to the TLIDB team. The underlying game facts belong to XD Inc., and the
community sources maintain their own compilations of those facts. TLI
Builder claims ownership of none of that. What is original to this
project is the export schema and structure, the verification database
(our own in-game testing), and this project's own additions and
corrections.

## What we ask

Please do not scrape, redistribute, rehost, or embed the compiled data
files that TLI Builder serves. That includes the JSON catalogs under
data/ and their packaged or exported forms (web-data/, engine-data.zip,
the data shipped with desktop releases, and the data served from
tlibuilder.com and its subdomains). This is not about the raw facts,
which anyone is free to gather. It is about lifting this project's
compiled dataset wholesale. Building and maintaining it each season takes
a lot of ongoing work, and TLI Builder is meant to be used at
tlibuilder.com and through the app itself.

## Questions
